What is Surface?

Surface is a small format for describing an application.

It records what the application should contain without choosing an implementation framework.

02

Is Surface a programming language?

No. Surface is a specification format rather than an executable language.

03

How does a screen get a URL?

Describe the URL path in the screen's logic.

Leave that instruction out for screens that are not addressable.

Surface keeps application intent readable by humans and LLMs.
