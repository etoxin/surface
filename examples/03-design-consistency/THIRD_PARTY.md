# Third-party assets

The `vendor/govuk-frontend-6.4.0` directory contains a configured stylesheet compiled
from [GOV.UK Frontend 6.4.0](https://www.npmjs.com/package/govuk-frontend/v/6.4.0).
GOV.UK Frontend code is released under the MIT License. Documentation and design-system
guidance are available under the Open Government Licence v3.0 except where stated
otherwise.

The stylesheet is compiled from `build.scss` with Dart Sass. The configuration replaces
GDS Transport and the GOV.UK brand colour as required for a service outside GOV.UK.
